Back last summer I posted a request on info.convex:

  |Has anyone run the SPEC benchmarks on a C2? If so, could you post the
  |results?

There were no responses. Several months later we obtained a license for
the SPEC 1.2b benchmark suite (SPEC89) and ran the suite on several of
our systems including our Convex C2. 

Since we were only interested in approximate SPEC metrics for the C2, we 
never bothered to shut our (busy) system down to single user mode to run 
the suite so that accurate elapsed time measurements could be made. Instead, 
we did the calculations using reported CPU time for each benchmark, rather 
than elapsed time as required by the SPEC run rules. 

  --> THUS THE NUMBERS REPORTED BELOW ARE *NOT* SPECratio89, 
  --> SPECint89, SPECfp89, and SPECmark89. 

However, since I/O is such a small component of the SPEC89 suite, we believe 
that the "Approximate Vax Equivalents" reported below are a good first 
order approximation (within a few %) of what the corresponding SPEC89
metrics would be. (Note that the results reflect the performance of a
single C2 processor.)

I am publishing these partial results in the hope of "flushing out" more 
accurate or up-to-date measurements for the Convex C2 (or C3) and perhaps
even some results for other mainframe/super vendors. After all, Convex is 
by no means the only vendor studiously ignoring the SPEC benchmark suites.
