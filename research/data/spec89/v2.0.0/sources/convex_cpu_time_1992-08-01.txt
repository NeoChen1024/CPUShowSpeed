Here are partial results for SPEC CPU benchmarks run on a Convex C3840.

Since we were only interested in approximate SPEC metrics for the C3, we 
didn't shut the (busy) system down to single user mode to get accurate
elapsed time measurements. Instead, we used reported CPU time rather
than elapsed time as required by the SPEC reporting rules. 

  --> THUS THE NUMBERS REPORTED BELOW ARE *NOT* SPECratio, 
  --> SPECfp92, SPECint92, SPECfp89, SPECint89, SPECmark89.

However, since I/O is such a small component of the SPEC suite, we believe 
that the "Approximate Vax Equivalents" reported below are a good first 
order approximation of what the corresponding SPEC metrics would be. 

Care was taken to minimize cache interference by doing timing runs when 
the load average was 3 or less on the four-processor 3840. In general,
elapsed time for these runs was close to CPU time.

O2, the highest level of uniprocessor optimization, was used for all 
compilations. While more exotic optimization flags were not explored, O2 
does a lot: basic block and program unit scalar optimization plus automatic 
vectorization.

Since the O3 (automatic parallelizing) option was not used, the results 
reflect the performance of a single C3 processor. 

This work was partially supported under grant TRA920241N by the National 
Center for Supercomputing Applications, University of Illinois at
Urbana-Champaign. I would like to thank Dave McWilliams, system manager
of the NCSA Convex C3, for his kind assistance.
