I know that many vendors publish system performance briefs.

We need a FAQ describing where and how one can obtain performance
briefs. I know that information can be obtained from DEC via ftp,
but the details get lost after a bit. I know that one can get 
performance briefs from Intel by calling Intel Literature at
(800) 548 - 4725.  But what about HP, IBM, SGI, Motorola, ..., etc.??

A FAQ containing information about obtaining performance briefs from
the various major computer system vendors would be very useful!

If the various vendors will volunteer this information I will pull all
the information together into a FAQ (an ASCII file called briefs.faq?)
and post it here (comp.benchmarks) occasionally (once per month?). Also
a copy will be kept at ftp.nosc.mil (and multiple copies should be 
spread elsewhere so that this information will indeed always available.
