# Research roadmap

Unchecked items are not implemented or verified. Move stable findings to their
owning document as work lands; remove superseded items.

- [ ] When historical PDF and KIPS extraction begins, choose a script-readable
      format and schema for checked values and related observations, define
      stable source/result IDs, and migrate existing checked numeric examples.
- [ ] Parse downloaded speed disclosures into validated system-result records,
      including requested threads, enabled hardware, and parallelism notes.
- [ ] Expand the CPU92–CPU95 overlap audit beyond the 13 reviewed x86 and
      PA-RISC configurations; check tuning notes and independent held-out
      systems before applying any bridge to the VAXen figure.
- [ ] Build a reviewed processor alias registry and tiered processor-level
      candidate matcher; keep ambiguous matches out of fitted cohorts.
- [ ] Review the automated CPU95–CPU2026 hardware-near overlap pairs against
      full disclosures, especially benchmark threads, memory layout, OS,
      compiler, and tuning, before adopting a VAXen conversion.
- [ ] Locate complete Fall 1989 and 1992 SPEC newsletter result issues.
- [ ] Recover the original McCalpin `spec.sc` and `spec.print` files; Helman's 40-row posted derivative is not either file.
- [ ] Trace 1989-10 `comp.arch` SPEC result posts cited by the DiMarco
      table and original Intel documents cited in the Juffa transcription.
- [ ] Evaluate MinerU or another OCR tool on representative historical scans;
      verify page mapping and table transcription before using extracted values.
- [ ] Expand and manually review CPU95–CPU2000 and CPU2000–CPU2006 overlap
      beyond the first automated fitting cohorts; recheck held-out error by
      processor family and vendor.
- [ ] Find a direct nonadjacent SPEC-generation overlap suitable for a real
      three-suite cycle check; the current exact hardware key has none.
- [ ] Reconstruct published instruction-mix values from original manuals.
- [ ] Inspect shortlisted bitsavers PDFs for model-specific timings and cite
      page numbers.
- [ ] Work through the [machine watchlist](machine-watchlist.md), including
      original LINC timing and Honeywell 6180 hardware revisions.
- [ ] Review the curated SPEC89 integer-score sources against their original
      publications, assess first-issue digitization, grade the 17 direct
      CPU89–CPU92 integer bridge rows by run configuration, and recover
      source-checked model introduction years for the 134 unresolved SPEC89
      labels before annual sensitivity-band plots.
- [ ] Assess CoreMark public score coverage and acquisition; inspect certified
      versus uploaded results and find same-system SPEC/CoreMark overlap.
- [ ] Define the first public timeline and its uncertainty display after the
      evidence above has been validated.
